# Original project context

The original Genius Kitchen prototype was created as a passion project after food in the author's household was repeatedly discovered only after expiring. It combined a local ingredient inventory, expiry tracking, recipe retrieval, multilingual presentation and a self-update mechanism for distributed Windows builds.

The current version was reconstructed from the original behaviour rather than copying the historical archive unchanged. Generated executables, recipe-image archives, private configuration and third-party material are intentionally omitted.
